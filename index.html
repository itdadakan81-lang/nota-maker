🖨️ Printer POS (mis. MP-58N)

Untuk printer thermal 58mm seperti MP-58N yang terhubung via kabel USB. Kebanyakan unit ini muncul di komputer sebagai port serial/COM (chip USB-Serial), jadi coba tombol Sambungkan (Serial/USB) terlebih dahulu. Jika tidak muncul, coba Sambungkan (WebUSB).
Catatan: fitur ini hanya berjalan di Chrome/Edge versi desktop (atau Chrome Android) dan halaman harus dibuka via https:// atau localhost — tidak akan berfungsi jika file dibuka langsung dari folder (file://).
Catatan Bluetooth: hanya berfungsi untuk printer Bluetooth Low Energy (BLE). Kebanyakan printer clone murah (termasuk sebagian MP-58N) memakai Bluetooth Classic/SPP yang tidak didukung oleh browser sama sekali — jika demikian, gunakan opsi Serial/USB atau WebUSB di atas.
